## 🌟 Overview

**RENT A CAR** is a state-of-the-art web application engineered for executive vehicle rentals across major metro hubs (Karachi, Lahore, and Islamabad). Built with a ultra-sleek dark glassmorphism aesthetic, dynamic GSAP animations, and seamless 24/7 WhatsApp concierge booking.

---

## ✨ Key Features

- 🏎️ **Curated Luxury Fleet Showcase:** High-performance sports cars, luxury SUVs, and executive sedans including Porsche 911 Carrera S, Mercedes-AMG G 63, BMW M5 Competition, Audi RS7, Toyota Land Cruiser 300, and Range Rover Vogue.
- ⚡ **GSAP & Lenis Motion Engine:** Ultra-smooth inertia scrolling, parallax photographic backdrops, dynamic image zooms, and responsive hover animations.
- 📍 **Multi-Metro Hub Switcher:** Interactive location browser with office addresses, maps, operating hours, and dedicated city concierge contacts for Karachi (DHA Phase 6), Lahore (Gulberg III), and Islamabad (Blue Area).
- 💬 **Direct WhatsApp Concierge Integration:** Instant one-click vehicle booking with custom pre-filled vehicle details and automated inquiry templates.
- 🎨 **Premium UI/UX System:** Glassmorphic card panels, gold gradient typography, responsive navigation, and mobile-optimized layouts.

## 🛠️ Technology Stack

- **Core Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tooling:** [Vite 8](https://vitejs.dev/)
- **Styling & Design System:** [Tailwind CSS](https://tailwindcss.com/) + Custom Glassmorphism Utilities
- **Animations & Smooth Scroll:** [GSAP](https://greensock.com/gsap/) + [@studio-freight/lenis](https://lenis.darkroom.engineering/)
- **Iconography:** [Lucide React](https://lucide.dev/)
- **Code Quality:** [Oxlint](https://oxc.rs/docs/guide/usage/linter.html)

## 🚀 Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Muhammad9985/rent-a-car.git
cd rent-a-car
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` (or the indicated port) in your browser.

### 4. Build for Production

```bash
npm run build
```
